# Local `.env` API Key Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load `OPENAI_API_KEY` from a Git-ignored project-local `.env` file without changing Windows user or system environment variables.

**Architecture:** A focused PowerShell loader reads only the `OPENAI_API_KEY` assignment and sets it in the current script process when no process-level key already exists. The transcription runner dot-sources that loader before its existing key validation; `.env.example` and README document the workflow.

**Tech Stack:** PowerShell 7/Windows PowerShell, .NET 8 CLI, Git ignore rules

- [ ] **Step 1: Write the failing PowerShell regression test**

Create `tests/powershell/ImportLocalEnv.Tests.ps1` that writes a temporary `.env`, dot-sources the loader, verifies file loading, then verifies that an existing process value wins. The test must print only `PASS` and never print either secret value.

```powershell
$ErrorActionPreference = 'Stop'
$loader = Join-Path $PSScriptRoot '..\..\scripts\import-local-env.ps1'
$temporaryDirectory = Join-Path ([System.IO.Path]::GetTempPath()) ([Guid]::NewGuid())
New-Item -ItemType Directory -Path $temporaryDirectory | Out-Null
$temporaryEnv = Join-Path $temporaryDirectory '.env'

try {
    [System.IO.File]::WriteAllText($temporaryEnv, "# local key`nOPENAI_API_KEY=file-value`n")
    Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue
    . $loader -Path $temporaryEnv
    if ($env:OPENAI_API_KEY -ne 'file-value') { throw 'File value was not loaded.' }

    $env:OPENAI_API_KEY = 'process-value'
    . $loader -Path $temporaryEnv
    if ($env:OPENAI_API_KEY -ne 'process-value') { throw 'Process value was overwritten.' }

    Write-Output 'PASS'
}
finally {
    Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue
    Remove-Item -LiteralPath $temporaryDirectory -Recurse -Force
}
```

- [ ] **Step 3: Implement the minimal loader**

Create `scripts/import-local-env.ps1`. It must return immediately when the process already has a key, ignore missing files/comments/blank lines, accept optional matching single or double quotes, read no variable except `OPENAI_API_KEY`, and never echo the value.

```powershell
[CmdletBinding()]
param(
    [string]$Path = (Join-Path $PSScriptRoot '..\.env')
)

if (-not [string]::IsNullOrWhiteSpace($env:OPENAI_API_KEY) -or
    -not (Test-Path -LiteralPath $Path)) {
    return
}

foreach ($line in Get-Content -LiteralPath $Path) {
    if ($line -notmatch '^\s*OPENAI_API_KEY\s*=\s*(.*)\s*$') { continue }
    $value = $Matches[1].Trim()
    if ($value.Length -ge 2 -and
        (($value.StartsWith('"') -and $value.EndsWith('"')) -or
         ($value.StartsWith("'") -and $value.EndsWith("'")))) {
        $value = $value.Substring(1, $value.Length - 2)
    }
    if (-not [string]::IsNullOrWhiteSpace($value)) {
        $env:OPENAI_API_KEY = $value
    }
    return
}
```

Dot-source it in `scripts/run-transcription.ps1` immediately before the existing key validation:

```powershell
. (Join-Path $PSScriptRoot 'import-local-env.ps1')

if ([string]::IsNullOrWhiteSpace($env:OPENAI_API_KEY)) {
    throw 'Set OPENAI_API_KEY in the project .env file or current process first.'
}
```

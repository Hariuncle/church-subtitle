# 레거시 자막기(Memo) 분석

`legacy/memo-subtitle/`에 보관된 수어방송용 자막 프로그램(자막기.exe)의 소스·바이너리 분석입니다.
커밋 4f231fc가 "나중에 디컴파일해서 2021년 변경분을 복구한다"는 목적으로 보관해 둔
`build-2021-07-01/자막기.exe`를 실제로 디컴파일해 2020 소스와 비교했고, 그 결과 **2021년
변경분을 전부 복구**했습니다. 디컴파일 소스는 `legacy/memo-subtitle/decompiled/`에 있습니다.

## 1. 프로그램 정체

- 충현교회 에바다부(수어방송)에서 만든 **자막 방송용 문자 입력기**. 도움말 메뉴에
  "충현교회 에바다부에서 만든 / 자막방송용 문자 입력기입니다"라고 명시되어 있습니다
  (`Form1.Designer.cs:457,464`).
- 기술적으로는 Windows 메모장 클론(프로젝트명 `Memo`)을 자막판으로 개조한 것입니다.
  C# WinForms, .NET Framework 3.5, 32-bit, 어셈블리 버전 1.0.0.0.
- 구조: `MainForm`(메인 화면 + 메모장 기능 전부) + 보조 다이얼로그 `Find`(찾기),
  `Change`(바꾸기), `Go`(줄 이동), `HangHelp`(제작자 정보). 자막기로서의 정체성은 로직이
  아니라 **디자이너 설정**(검정 배경, 흰 글자, 대형 폰트, 하단 입력 밴드)에 있습니다.
- 운영 방식(설정에서 추정): 방송실 PC의 **두 번째 모니터**에 풀스크린으로 띄워 놓고
  운영자가 실시간으로 타이핑하면, 방송 장비가 그 화면을 수어방송 화면에 합성합니다.
  `ShowInTaskbar=false`, `ControlBox=false`로 방송 화면에 창 테두리·작업표시줄이 노출되지
  않게 했습니다.

## 2. 버전 계보 — 세 가지 버전이 서로 다름

저장소에는 사실상 **세 개의 버전**이 있고, 셋 다 다릅니다.

| | `Memo/bin/Debug/Memo.exe` | 체크인 소스 (`Memo/`) | `build-2021-07-01/자막기.exe` |
| --- | --- | --- | --- |
| 시점 근거 | PE 링크 시각 2020-04-04 11:50 UTC | 2020-04-04 스냅샷 (커밋 63b6791) | PE 링크 시각 2021-07-01 06:14 UTC |
| 자막 폰트 | HY견고딕 30pt | 나눔고딕 ExtraBold 40pt Bold | 나눔고딕 ExtraBold **52pt** Bold |
| 자막 영역 | 하단 밴드 504×170, 남색 RGB(37,64,97) | 창 전체 (0,30) 504×416, 남색 | **하단 밴드 1920×211, 진회색 RGB(71,71,71)** |
| 창 | 504×446 일반 창 | 504×446 일반 창 | **1920×1080 보더리스, 위치 (1921,0) = 두 번째 모니터** |
| 상태바 | Navy + "충현교회 에바다부가 개발한 캡션보드입니다." | Black, 문구 없음 | Black, 문구 없음 |

- `bin/Debug/Memo.exe`는 **체크인 소스보다 오래된 빌드**입니다. 같은 날(2020-04-04) 빌드한 뒤
  소스를 더 수정하고(폰트·상태바 변경) 재빌드 없이 스냅샷이 남은 상태입니다. 따라서 "저장소의
  exe = 저장소의 소스"라고 가정하면 안 됩니다.
- 데스크톱 폴더명은 `자막기_20210701_글자크기55텍스트박스`지만 실제 2021 바이너리의 폰트는
  **52pt**입니다(55는 시도했다가 되돌렸거나 폴더명만 남은 것으로 보임).

## 3. 2021-07-01 빌드에서 복구한 변경 내역 (핵심)

디컴파일 diff 결과, `Change/Find/Go/HangHelp/Program` 및 `MainForm`의 **이벤트 핸들러 로직은
2020 빌드와 100% 동일**합니다. 2021년 변경은 전부 `InitializeComponent()`의 디자이너 값이며,
"작은 창 메모장"을 "세컨드 모니터 풀스크린 캡션보드"로 바꾼 것입니다.

1. **폼**: ClientSize 504×446 → 1920×1080, `FormBorderStyle=None`, `StartPosition=Manual`,
   `Location=(1921,0)`. 주 모니터가 1920px일 때 x=1921은 두 번째 모니터의 왼쪽 위 —
   즉 부팅 후 실행만 하면 자막 출력 모니터에 풀스크린으로 뜹니다.
2. **자막 텍스트박스**: 위치 (0,276)→(0,869), 크기 504×170→**1920×211** (Anchor는 두 빌드 모두
   Bottom|Left|Right). 화면 하단 약 20%를 자막 밴드로 사용하며, 52pt 줄 높이(약 83px) 기준
   **약 2줄**이 보입니다.
3. **폰트**: HY견고딕 30pt → 나눔고딕 ExtraBold 52pt Bold(한글 charset 129).
4. **색**: 자막 밴드 배경 남색 RGB(37,64,97) → 진회색 RGB(71,71,71). 글자는 흰색 유지.
5. **상태바**: Navy + 개발부서 문구 → Black, 문구 제거 (방송 화면에 노출되는 요소 정리).
6. 폼 아이콘 리소스 추가 (`ComponentResourceManager` 도입).

체크인 소스(2020-04-04)는 이 중 폰트 교체·상태바 정리·아이콘까지는 이미 반영된 중간
단계이고, **풀스크린/세컨드 모니터/52pt/하단 밴드/진회색**이 소스가 유실된 2021년 변경분입니다.

## 4. 코드 품질 — 운영에 실제로 영향 있는 버그

운영자가 실제로 겪었을 함정 순으로 정리합니다. 레거시는 신규 시스템 장애 시 수동 fallback으로
계속 쓰일 수 있으므로(README의 수동 자막 전환 안내), 알아둘 가치가 있습니다.

1. **시작 직후에는 종료가 안 됨** (`Form1.cs:49-75`): `MainForm_FormClosing`이
   `EditText == false`면 닫기를 무조건 취소합니다. 로직이 반대로 짜여 있어("수정 안 했으면
   닫기 금지") 실행 직후에는 끝내기(Ctrl+X)도 Alt+F4도 안 먹히고, **한 글자라도 입력해야 종료
   가능**합니다. 그 아래 저장 확인 블록은 도달 불가능한 죽은 코드이며, 도달한다 해도
   `saveFileDialog1.ShowDialog()`를 두 번 띄우는 버그(`Form1.cs:69`)가 있습니다
   (SaveFileDialog는 `DialogResult.No`를 반환하지 않으므로 비교 자체도 무의미).
2. **한 번 저장하면 다시 저장 안 됨** (`Form1.cs:400-428`): `SaveYorN()`은 `SaveCheck == true`면
   아무것도 하지 않습니다. 최초 저장 후 내용을 수정하고 Ctrl+S를 눌러도 **조용히 무시**됩니다.
   "저장"과 "다른 이름으로 저장"(`Form1.cs:146-149`)이 같은 함수를 부르므로 구분도 없습니다.
   함수는 항상 `false`를 반환해 반환값도 무의미합니다.
3. **CP949 인코딩** (`Form1.cs:433,444`): 저장·열기 모두 `Encoding.Default`(한국어 Windows에서
   CP949). UTF-8 파일을 열면 깨지고, CP949에 없는 문자는 저장 시 유실됩니다.
4. **단축키 충돌** (`Form1.Designer.cs`): Ctrl+A가 "다른 이름으로 저장"(166행)과
   "모두선택"(340행)에 중복, Ctrl+U가 "페이지 설정"(179행)과 "실행취소"(233행)에 중복.
   잘라내기가 Ctrl+T(258행)이고 **Ctrl+X는 끝내기**(200행)라 표준 습관대로 누르면 프로그램이
   종료됩니다(위 1번 버그 때문에 편집 전이면 살아남는 게 역설적 안전장치). Delete 키는 삭제가
   아니라 `Cut()`을 호출해(`Form1.cs:184`) **클립보드를 덮어씁니다**.
5. **인쇄 디버그 잔재** (`Form1.cs:457-485`): 인쇄하면 `MessageBox.Show("아하하하하하하")`와 본문
   전체를 담은 메시지박스가 뜨고, 전체 텍스트를 `DrawString` 한 번으로 그려 **한 페이지만**
   출력됩니다(페이지네이션 변수 `line`이 항상 null). 한글 본문에 Arial 폰트를 씁니다.
6. **줄 이동 상태 오염** (`Form1.cs:207-229`, `Go.cs:36-40`): Go 다이얼로그에서 취소를 눌러도
   직전 입력값으로 이동하고, 호출마다 `moveLine`이 1씩 줄어드는 부작용이 있습니다. 빈 입력이면
   `int.Parse` 예외가 나고, 숫자가 아닌 글자는 한 글자 입력할 때마다 메시지박스가 뜹니다
   (`Go.cs:22-34`).
7. **바꾸기 미완성** (`Change.cs:26-45`): 클릭당 다음 1개만 교체하고 "모두 바꾸기"가 없습니다.
8. **시간/날짜 삽입** (`Form1.cs:238-241`): `TextBox.Text` 전체를 재할당해 커서 위치와 RTF
   서식이 초기화됩니다.
9. **자동 저장·복구 없음**: 방송 중 크래시 시 그날 입력분이 통째로 유실됩니다.
10. **죽은 코드**: `tb, txtLine, txt, cLength, search` 필드, `MainForm(int)` 생성자,
    `new Find FindForm` 선언(`Form1.cs:31`), 정렬 핸들러 3종(`Form1.cs:356-371` — `Img/`에
    정렬 아이콘까지 있으나 툴바에 버튼이 배치되지 않음), "다음 찾기"(F3)와 "메모장 정보"의 빈
    핸들러.

## 5. 빌드 재현성

- `Memo.csproj:96-98`이 `Form1.ko-KR.resx`를 EmbeddedResource로 참조하지만 **파일이 저장소에
  없어** 이 소스는 그대로는 빌드가 실패합니다. 빌드하려면 해당 ItemGroup을 제거해야 합니다.
- TargetFramework v3.5라서 최신 Visual Studio에서는 .NET Framework 3.5 developer pack이
  필요합니다.
- 2021 빌드의 원본 소스는 유실 상태이며, 재현하려면 체크인 소스에 §3의 디자이너 변경을
  적용하면 됩니다(로직 변경 없음).

## 6. 신규 시스템(ChurchSubtitle PoC)에 주는 시사점

레거시가 실제 운영을 거치며(2020→2021 튜닝) 수렴한 출력 스펙이 곧 검증된 요구사항입니다.

- **출력 화면**: 두 번째 모니터 1920×1080 풀스크린, 창 장식 없음.
- **자막 밴드**: 화면 하단 211px(약 20%), 배경 진회색 RGB(71,71,71), 글자 흰색,
  나눔고딕 ExtraBold 52pt Bold, **약 2줄** — 현재 PoC 테스트 UI의 "하단 2줄 rolling" 정책과
  일치합니다. 운영 클라이언트 화면을 만들 때 이 수치를 기본값으로 삼으면 시청자가 보는 화면이
  기존과 달라지지 않습니다. 이 스펙은 테스트 UI의 송출 화면(`/output.html`)에 뷰포트 비율로
  구현되어 있습니다.
- **fallback 운영 매뉴얼**: 신규 시스템 장애 시 레거시로 전환한다면 §4의 1·2번(시작 직후 종료
  불가, 저장 1회 후 재저장 무시)과 4번(Ctrl+X = 종료)은 운영자에게 반드시 공지할 함정입니다.
